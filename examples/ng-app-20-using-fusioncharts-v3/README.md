# ng-app-20-using-fusioncharts-v3 — FusionCharts v3 compatibility example

> ⚠️ **Use the latest FusionCharts in your own projects.**
>
> This example **deliberately pins FusionCharts `3.23.0`** for one purpose only: to demonstrate that
> `angular-fusioncharts` still supports FusionCharts **v3**. FusionCharts v3 is a legacy line; for the
> latest features, fixes, and dependency updates, use the **latest FusionCharts (4.x)** in real or
> production applications — do not copy the pinned version from this example.

This app is a copy of `ng-app-20-using-fusioncharts-v4` with only the FusionCharts version changed, used
to validate the `fusioncharts: "^3.0.0 || ^4.0.0"` peer range.
